# Redis Server

[English version](https://github.com/alekslegkih/ha-addons/blob/main/redis-server/README_EN.md)

Аддон для **Home Assistant**, предоставляющий сервер Redis для использования в качестве кэша.

Работает в фоновом режиме и предназначен для подключения других аддонов и сервисов, например Nextcloud.

## Возможности

- Лёгкий и быстрый сервер Redis
- Работает как кэш: при переполнении памяти вытесняются старые ключи
- Постоянное хранилище отключено — данные живут только в памяти
- Минимальная настройка и лёгкий запуск
- Порт наружу не публикуется, доступ только внутри сети Home Assistant

> [!NOTE]
> Аддон рассчитан на использование как кэш, а не как постоянное хранилище.
> После перезапуска данные не сохраняются — это нормальное поведение для кэша.

## Настройки

### Максимальный объём памяти (`maxmemory`)

Лимит памяти, который Redis может использовать.

Пример: `128mb`

> Если не задано, используется значение по умолчанию `128mb`.
> Для домашнего использования с небольшим числом пользователей этого достаточно.

### Политика вытеснения (`maxmemory_policy`)

Что делать, когда память заполнена.

Доступные значения:

- `noeviction` — не вытеснять, возвращать ошибку при записи
- `allkeys-lru` — вытеснять давно не использованные ключи (рекомендуется для кэша)
- `allkeys-lfu` — вытеснять редко используемые ключи
- `allkeys-random` — вытеснять случайные ключи
- `volatile-lru` — вытеснять давно не использованные ключи с TTL
- `volatile-lfu` — вытеснять редко используемые ключи с TTL
- `volatile-random` — вытеснять случайные ключи с TTL
- `volatile-ttl` — вытеснять ключи с наименьшим TTL

Пример: `allkeys-lru`

> Если не задано, используется значение по умолчанию `allkeys-lru`.

## Как это работает

Аддон запускает `redis-server` с сгенерированным конфигом.

- Данные хранятся только в оперативной памяти
- Постоянное хранилище (RDB/AOF) отключено
- При заполнении памяти старые ключи вытесняются согласно выбранной политике
- Доступ к серверу возможен только из внутренней сети Home Assistant

Для подключения другого аддона или сервиса используйте **имя (slug) этого аддона** в качестве хоста, например:

```php
'host' => 'redis-server',
'port' => 6379,
```

## Частые проблемы

### Другой аддон не может подключиться

- Проверьте, что в настройках клиента указано имя (slug) аддона, а не localhost
